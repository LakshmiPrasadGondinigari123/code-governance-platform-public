# Production backend contract (snapshot)

`openapi.json` is the API contract of the live production backend (v0.6.0) taken on 2026-10-13.
The backend's source code was deployed straight from a developer machine and could not be recovered; this contract,
together with `production-frontend/`, is what the live system exposes and consumes.
The rebuilt platform in `app/` implements the same contract plus the additions listed in the root README.
